# Blender 操作插件 1.4.0

[English](README.md) · [贡献与测试说明](CONTRIBUTING.md)

适用于 **Unreal Engine 5.4 / Windows Win64 关卡编辑器**。提供对象操作、多物体点边面编辑、面挤出和四边面环切。本插件仅用于编辑器，无需安装 Blender；当前工具栏、菜单和提示为中文。

## 从源码安装

需要 **UE 5.4**、**Windows x64**、**Visual Studio 2022 及适用于 UE 5.4 的 C++ 工具链**。Visual Studio 应安装“使用 C++ 的游戏开发”工作负载、兼容的 MSVC 工具集和 Windows SDK。插件依赖 **Modeling Tools Editor Mode（建模工具编辑器模式）**，内部名称为 `MeshModelingToolset`，已在插件描述文件中声明。

1. 保存项目并关闭目标项目的编辑器，再安装或替换插件文件。
2. 把**整个仓库**放到 `<你的项目>/Plugins/BlenderStyleControls/`。`BlenderStyleControls.uplugin` 应直接位于这个目录，与 `Source`、`Content`、`Resources` 同级，避免多套一层解压文件夹。
3. 使用 C++ 项目。纯蓝图项目可先在 UE 中添加一个空 C++ 类，生成项目编译目标后再关闭编辑器。
4. 右键 `.uproject` 生成 Visual Studio 项目文件。打开解决方案，选择 **Development Editor** 和 **Win64**，编译项目的 Editor 目标。
5. 用 UE 5.4 打开项目，在 **编辑（Edit）→ 插件（Plugins）** 中确认 **Blender Style Controls** 及上述建模依赖已启用，按提示重启。
6. 点击关卡编辑器顶部的 **Blender 操作：关**，开始使用。

第 2 步也可以在项目根目录执行以下可选克隆命令：

```text
git clone https://github.com/Asz7/BlenderStyleControls.git Plugins/BlenderStyleControls
```

仓库提供源码，需要在本机编译。其他 UE 版本和平台尚未验证，不视为当前支持范围。

## 开关

关卡编辑器顶部的 **Blender 操作：关** 按钮，点击后变为绿色的 **Blender 操作：开**。再次点击关闭；“工具”菜单也有开关和操作说明。每次启动默认关闭。

快捷键在关卡视口内使用。关闭后恢复 UE 默认键位；文本框、蓝图编辑器不接管。

## 镜头与显示

开启插件后使用 Blender 默认键位导航，右键飞行和 UE 的镜头拖动停用。相机变化只作用于编辑视角。

| 按键 | 功能 |
|---|---|
| 中键拖动 | 围绕视图中心旋转 |
| Shift+中键拖动 | 平移视图 |
| 滚轮 / Ctrl+中键拖动 | 缩放视图 |
| Ctrl+Shift+中键拖动 | 前后推移视点与视图中心，保持环绕距离 |
| 小键盘 . | 聚焦所选物体或所选点边面 |
| Home | 聚焦所有物体；网格编辑时聚焦本次编辑的全部几何 |
| 小键盘 1 / 3 / 7 | 前 / 右 / 顶视图；按住 Ctrl 看相反方向 |
| 小键盘 2 / 4 / 6 / 8 | 分步旋转视图 |
| 小键盘 5 | 切换透视投影和正交投影 |
| Z | 打开着色菜单 |
| Shift+Z | 线框与此前的着色方式切换 |
| Alt+Z | 实体/线框的透视选择开关，与正交投影开关无关 |

右上角依次有**线框、实体、材质预览、渲染、透视**按钮。线框与实体分别记住透视状态；材质预览和渲染中该按钮停用。编辑模式开启透视后，预览半透明，后面的点边面也能选择和框选。关闭后按遮挡判断可选元素。

实体模式使用明亮、随视角转动的棚光；右上角新增 **叠加** 与 **着色** 下拉菜单。材质预览现在使用 HDRI 照亮模型的原材质，会显示粗糙度、金属和高光响应。渲染模式仍使用关卡灯光。

**着色 → 实体**：均衡 / 柔和 / 轮廓光三种棚光，亮度与旋转；23 个 Blender 自带 MatCap 球形缩略图，可水平翻转；平面显示、腔体和形体轮廓增强。默认中性灰色，选中的点边面才显示选择颜色。

**着色 → 材质预览**：8 套 Blender 自带 HDRI（city、courtyard、forest、interior、night、studio、sunrise、sunset），默认 forest；环境强度、背景不透明度、背景模糊、仅背景旋转；可独立选择使用场景灯光和场景世界。默认背景不透明度为 0，模型仍受 HDRI 照亮；调到 1 才显示全景天空。

**叠加**：总开关、地面网格与轴线、所选物体轮廓、灯光等辅助图标、操作提示文字、物体原点、线框叠加和线条不透明度/粗细。对象线框遵循静态网格的真实多边形边，支持静态网格实例；编辑状态显示可编辑的点边面。已三角化的模型仍会看到三角边。

以上均是编辑器当前会话的显示选项，不创建天空或灯光 Actor，不替换模型的已保存材质，不保存关卡。退出插件会恢复此前的视口显示，PIE/游戏和场景捕获不使用这些预览效果。首次开启需要完成少量预览着色器准备。

限制：使用 UE 5.4 延迟渲染路径，并非移植 Blender Workbench 渲染器；腔体/轮廓为屏幕空间近似。**背景旋转不旋转环境照明方向**。材质预览保留默认 AfterDOF 透明物体；特意设为 BeforeDOF 的透明材质朝向天空时可能被背景覆盖，可勾选“场景世界”查看原显示。场景天空自动隐藏只识别标记为 Sky 的材质，普通材质的大天空球仍被视为模型。未实现 Blender 的骨骼、运动路径、注释、面朝向或合成器菜单。

对象模式的透视提供穿透框选和网格边辅助，半透明预览用于网格编辑。实体透视时保留原有半透明显示，暂不应用棚光/MatCap/背景替换。原生 UE 线框仍可能显示被遮挡的三角线，透视关闭时选择会检查遮挡。

贴图来源与 CC0 授权见 `Resources/PreviewV14/RESOURCE_LICENSES.md`，未复制 Blender GPL 实现代码。

UE 5.4 的正交视图有轴向限制：从任意角度按小键盘 5，会取最近轴向，切回时恢复此前透视角度。正在驾驶/锁定到场景 Actor 的相机不接管，以免移动场景里的相机物体。

## 框选、循环和路径

| 按键 | 功能 |
|---|---|
| B，然后左键拖动 | 框选加选；中键拖动减选；Esc/右键取消 |
| 直接左键拖动 | 新框选；Shift 加选，Ctrl 减选，Ctrl+Shift 取交集 |
| Alt+左键点边 | 选择循环边；面模式沿点击的边选择面循环 |
| Shift+Alt+左键 | 加选/取消该循环，保留其他选择 |
| Ctrl+Alt+左键 | 选择环带；加 Shift 可加选/取消 |
| Ctrl+左键 | 从当前活动点/边/面到目标计算最短路径，并选择或取消路径 |
| Ctrl+Shift+左键 | 填充两端之间的拓扑路径区域 |
| Ctrl+小键盘 + / - | 扩大/缩小一圈选择 |
| 鼠标指向元素后 L | 选择相连部分；Shift+L 取消相连部分 |
| Ctrl+L | 从当前选择扩展到相连部分 |

点击、路径、循环都可与多个物体共同编辑配合；路径本身不能跨越不相连的模型。最短路径按模型几何距离和拓扑计算，使用最后的活动元素作为起点。普通路径保留其他已选部分；路径已全部选中时会取消。

循环依赖模型真实的多边形结构。四边面网格可形成规则循环和环带；导入后只剩三角面的网格不能自动恢复 Blender 原来的四边面拓扑。遇到极点、边界或不支持的分支时按实际连接停止。

框选点按投影位置；边先选完整包含的边，没有合适完整边时才回退到相交边，逐个物体处理。透视下的面按面中心框选，普通模式检查矩形内可见的面片段。普通静态模型遮挡按几何计算，不要求有碰撞；实例网格和其他组件仍使用碰撞回退。极细遮挡缝隙的框选采用片段采样，可能与 Blender 的逐像素选择有差异。

## 对象操作

| 按键 | 功能 |
|---|---|
| Shift+A | 添加立方体、平面、球、圆柱、圆锥 |
| G / R / S | 移动 / 旋转 / 缩放所选物体 |
| G、R 后按 X/Y/Z | 世界轴；重复同一轴切本地轴，第三次解除 |
| S 后按 X/Y/Z | 各物体沿自身本地轴缩放；重复同一轴解除 |
| Shift+D | 复制所选物体并移动，副本先复用原模型资源 |
| Tab | 编辑所选静态模型的点、边、面 |
| Ctrl+Z | 撤销已确认的对象操作 |

多物体移动、旋转和等比缩放使用选择中心；等比缩放也改变物体间距。对象单轴缩放使用各自原点。G/R 的共同本地轴方向取首个有效选中物体。

## 多物体网格编辑

先在对象模式选中一个或多个静态网格物体，按 **Tab** 一起进入编辑。各个模型仍是独立物体，进入时不自动选择点、边或面。实体表面保持灰色，只有选中的元素高亮；按 A 才全选。

| 按键 | 功能 |
|---|---|
| 1 / 2 / 3 | 点 / 边 / 面选择模式 |
| 左键 | 选择一个可见元素，替换当前选择 |
| Shift+左键 | 加选或减选，可跨多个物体 |
| A / Alt+A | 全选 / 清空选择 |
| G / R / S | 统一移动、旋转、缩放选中的几何部分 |
| X/Y/Z（变换中） | 世界轴；重复同轴切本地轴，第三次解除 |
| Ctrl+Z | 撤销本次编辑中的已确认变形 |
| Ctrl+Shift+Z / Ctrl+Y | 重做 |
| Tab（未在变换中） | 提交本次网格编辑并返回对象模式 |
| Esc（未在变换中） | 放弃整次网格编辑并恢复原模型 |

跨物体选择的顶点围绕共同中心变换；网格模式的单轴缩放也使用这个中心。共同本地轴取首个编辑物体的方向。镜头使用上面的中键组合键。

例如：选择两块木板 → Tab → 1 → 左键选第一块上的点 → Shift+左键加选第二块上的点 → G → Z → 10 → 回车。两个点一起向世界 Z 方向移动 10 厘米；再按 Tab 提交。

## 挤出与环切

先按 Tab，再按 **3** 切到面选择，选中要挤出的面。

| 按键 | 功能 |
|---|---|
| E | 区域挤出，沿所选区域的平均法线移动新面 |
| Alt+E | 打开挤出菜单，可选区域挤出或沿法线挤出 |
| 挤出中 X/Y/Z | 改沿世界轴移动；再次按同一轴恢复默认法线方向 |
| 鼠标移动 / 输入数字 | 调整挤出距离，数字单位为厘米 |
| 回车 / 左键 | 确认挤出 |
| 挤出中 Esc / 右键 | 取消移动，保留零距离挤出的新结构；Ctrl+Z 才撤销这次挤出 |
| Ctrl+R | 将鼠标放在四边面上，预览一圈环切 |
| 第一次左键 | 插入居中的切线，进入滑移 |
| 鼠标移动 / 数字 −1..1 | 调整滑移；**0 表示居中** |
| 第二次左键 / 回车 | 确认位置 |
| 环切预览时 Esc / 右键 | 不插入，取消环切 |
| 已插入后的 Esc / 右键 | 结束滑移并把切线放回中间，保留环切；Ctrl+Z 撤销 |

`E → 25 → 回车`：挤出 25 厘米。`Ctrl+R → 左键 → 0 → 回车`：保留居中的一圈切线。切换窗口会回滚尚未确认的当前拓扑操作；关闭插件、换地图或退出整个编辑会话会放弃未提交内容。

这版的挤出用于**面区域**，尚不支持孤立点和边的挤出。沿法线挤出使用各顶点相邻所选面的平均法线。新侧壁继承相邻面的材质并生成简单条带 UV，原有面角的 UV、颜色和材质组保留；有贴图的侧壁可按需要继续调整。

Ctrl+R 当前一次切一圈，需要连续、有效的四边面带。遇到三角面、多边面、非流形边或方向冲突，会拒绝这次环切并提示原因。插件 **Shift+A → 立方体** 新建的模型保留六个真正的四边面，适合直接练习挤出和环切。旧版立方体及已三角化的导入模型不会自动变成四边面。

新增立方体模型位于 **Content/BlenderPrimitives**；提交编辑后的独立模型仍位于 **Content/BlenderEdits**。两者都沿用正常的保存流程。

## 变换时的共同操作

- **回车或左键**确认本次 G/R/S；**Esc 或右键**取消本次变换。网格模式取消后仍留在编辑中，之前确认的变形保留；对象复制操作取消时会移除本次副本。
- 可输入数字、负号、小数点，退格修改。移动单位为**厘米**，旋转为**度**，缩放为**倍率**。
- 按住 Ctrl 使用 UE 当前吸附步长；按住 Shift 精细调整鼠标。
- 锁轴后出现穿过本次选择中心的长参考线：**X 红、Y 绿、Z 蓝**。切换世界轴或本地轴时，线的方向随之改变。
- `G → X → 200 → 回车`：沿世界 X 移动 2 米；`R → Z → 90 → 回车`：旋转 90 度；`S → 2 → 回车`：等比放大到 2 倍。

切到其他窗口会取消尚未确认的 G/R/S，网格编辑会话继续保留。关闭开关、切换编辑模式、切地图或准备运行游戏时，会放弃尚未提交的整次网格编辑；需要保留时，请先确认变换，再按 Tab。

## 提交、资源与保存

编辑期间显示临时预览。按 Tab 提交时，**仅为几何有改动的物体创建独立模型**，包括位置变化和新增拓扑，并替换这些物体的模型引用。原模型资源和其他共享它的物体保持原样；未修改物体不生成副本。

新模型放在内容浏览器的 **Content/BlenderEdits**（资源路径 `/Game/BlenderEdits/`），名称以原模型名加 `_Edit` 开始，重名时自动编号。

提交后模型和关卡处于待保存状态，插件不自动写入磁盘。**先按 Tab 完成网格编辑，再按 Ctrl+Shift+S 保存模型和关卡。** 网格编辑中按 Ctrl+S 或 Ctrl+Shift+S 会提示先完成编辑，不会把临时预览当作已保存。

提交后可用 UE 的 Ctrl+Z 恢复关卡中原来的模型引用；已创建的独立资源不会因此自动删除。

## 当前支持范围

支持普通静态网格物体的位置调整、面区域挤出和单圈四边面环切。保留材质、原有面角 UV 和模型资源自身的顶点颜色；新增元素按上述规则继承或插值。变形后会重新计算表面法线和切线，原有自定义明暗效果可能变化。

以下功能或模型本版不支持：

- 孤立点/边挤出、任意删点删面、焊接、倒角、自由切刀、细分和网格内复制；环切尚不支持滚轮一次插入多圈。
- 骨骼模型、蓝图组合物体、多个几何组件，以及 ISM/HISM 内部的单个实例。
- 多个 LOD、独立高精度源模型，或没有可编辑源顶点与面的模型。
- 在关卡实例上做过顶点涂色的物体；为保留这些涂色，本版会拒绝进入编辑。这与模型资源自身的顶点颜色不同。
- 已锁定、隐藏、只读关卡中的物体，以及正在模拟物理或缩放为零的物体。

所选物体中只要有一项不符合条件，整组不会进入编辑，并显示原因。若源模型导入时已三角化，面选择也会保留三角面，不会自动还原成四边面。

新模型使用变形后的表面作为碰撞，不沿用可能已经错位的旧简单碰撞。它适合静态场景碰撞；如果以后需要让物体模拟物理，应先为新模型重新制作简单碰撞。

卸载时可在“编辑 > 插件”中禁用 **Blender Style Controls**，然后重启编辑器。

## 验证状态

本次发布审查确认 **29 个源码文件**与原安装逐字节一致。**31 个预览纹理**均在独立的 **UE 5.4 纯内容宿主工程**中成功加载并导出其保存的源图像；源图尺寸、sRGB 与压缩设置均核对通过：8 个 World TextureCube 的源图为 1024 × 512，23 个 MatCap Texture2D 为 512 × 512，均关闭 sRGB 并使用 HDR 压缩；8 个 World 纹理均为 `TMGS_ANGULAR`。这验证了资源加载和源图导出，尚不等于插件视口渲染验证。

1.4.0 先前开发验证记录包括：Windows 编辑器目标编译通过、**41/41 项预览针对性检查通过**，以及 **9 张离屏视口图像检查通过**。本次发布审查**没有重新编译或重跑上述检查**，也没有进行物理鼠标键盘人工验收或游戏打包。跨平台兼容性仍未验证。

贡献者应按改动范围运行小规模检查；测试必须在独立、可丢弃的工程和单独编辑器进程中执行。测试会创建和丢弃临时关卡，不能在含有用户工作或未保存内容的编辑器里运行。具体入口见 [CONTRIBUTING.md](CONTRIBUTING.md)。
